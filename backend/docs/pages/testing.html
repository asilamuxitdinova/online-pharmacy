Endpoints

EndpointDoes
GET /_test/inbox/viewThe demo inbox in a browser: one-time codes, notices and webhook deliveries.
GET /_test/inbox?recipient=…&kind=otpThe same as JSON, newest first.
POST /_test/resetWipes everything and seeds it again.
GET /_test/fail?status=503&delay=3Fails on request. flaky_key=x fails on odd calls and works on the retry. mode=close drops the connection.
GET /_test/delay?seconds=10Waits, then answers. For timeouts.
POST /_test/webhooksA webhook receiver that checks X-Webhook-Signature: sha256=<hex HMAC of "timestamp.body"> and X-Webhook-Timestamp. Every delivery shows in the inbox, verified or not.
GET /_test/configThe current non-secret settings: token lifetimes, thresholds, whether the fixed one-time code is on.

Useful settings

ACCESS_TOKEN_TTL=60s makes renewal visible within a minute. FIXED_OTP_CODE=123456 makes every one-time code predictable for scripted demos. JOB_DURATION=15s sets how long slow jobs take.
