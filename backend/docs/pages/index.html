Test Pharmacy

Test Pharmacy is an online pharmacy that exists only to test Frege. Everything in it is made up: the medicines, the people, the card numbers and the taxpayer numbers. You can reset it to a clean state at any time.

Customers browse medicines, upload prescriptions, place orders, pay with a card and ask for refunds. Pharmacists (the staff role) review prescriptions and larger refunds. Administrators manage accounts.

Where to start

  • OpenAPI specification: every endpoint, used as Frege's tool list.
  • Authentication: password, one-time codes, OAuth 2.0 with PKCE, API keys, session cookies and signed requests.
  • Roles: what customers, pharmacists and administrators may do.
  • Refund policy and delivery: the business rules, with amounts.
  • Error codes: every error the API returns and what to do about it.
  • Testing helpers: seeded accounts, test cards, the demo inbox and failures on request.

Basics

All amounts are whole Uzbek soʻm (UZS), for example "price": 4000. Times are UTC in RFC 3339 format. Product names and many messages are available in English, Russian and Uzbek: send Locale: ru or Locale: uz (or the standard Accept-Language header).
